MemOIR: Driving Video Generation from View-Space Blocks World with Object-Level Memory

Rebuttal video results. Videos in each block play in sync; use the tabs to switch between scenes.

1. Robustness 2. Beyond Vehicles 3. Wan2.1-VACE 4. Zero-Shot Lyft 5. Single Image

1. Robustness to Noisy Inputs

1.1 Noisy Box Conditions

nuScenes validation scenes with one target vehicle's box jittered or dropped in random frames: MemOIR still renders a smooth, coherent vehicle along the underlying trajectory.

1.2 Identity Switch Within a Chunk

A vehicle briefly leaves the frame and returns under a different instance ID in the same chunk; its appearance is preserved.

2. Instance Memory Beyond Vehicles

2.1 Pedestrians: Forward–Reverse Revisit

Zero-shot Lyft L5: the second chunk replays the drive in reverse, so every pedestrian is revisited; with memory they keep the appearance they first had.

2.2 Buildings: Forward–Reverse Revisit

The same protocol for buildings: without memory, facade details such as windows change after the chunk boundary; with memory they are restored.

3. Instance Memory on Wan2.1-VACE

3.1 Faces (CelebV-HQ)

The chunk boundary falls mid-turn, while the face is hidden; the frontal face in the next chunk can only come from memory.

3.2 Pedestrians (WalkingTours)

The chunk boundary falls while the person is out of view; with memory, the returning person is regenerated with the same identity.

4. Zero-Shot Comparison on Lyft L5

4.1 Same Initial Frame for Every Method

15.4 s generations on Lyft L5, which no method saw in training; every method receives the same real initial frame.

4.2 Full-Chunk Fine-Tuning

Fine-tuning on full 93-frame chunks instead of 25-frame clips removes the drift in later frames of each chunk.

5. Blocks World from a Single Image

5.1 Automatic Construction

From a single RGB image, with off-the-shelf models only and no annotations, maps or LiDAR, to an editable blocks world and the generated video.

5.2 Agent Refinement

An LLM agent compares the rendered world with the image, corrects buildings, and adds missing structures before generation.
